# smart-parking-analytics-system# 🚗 Smart Parking Analytics System

A real-time **Smart Parking Analytics System** built with **FastAPI, MongoDB, Apache Kafka, Docker, JWT Authentication, HTML, CSS, and JavaScript**.

The system simulates parking-slot activity, processes parking events through Kafka, stores real-time parking information in MongoDB, and provides a web-based dashboard for monitoring parking occupancy and analytics.

---

## 📌 Project Overview

Managing large parking facilities manually can be inefficient and difficult to scale.

This project provides a smart, event-driven parking management system that can:

- Monitor parking-slot occupancy
- Simulate vehicle entry and exit events
- Process parking events using Apache Kafka
- Store parking and vehicle information in MongoDB
- Provide REST APIs using FastAPI
- Authenticate users using JWT
- Provide a web-based parking dashboard
- Track parking transactions and billing
- Generate parking analytics
- Run the complete system using Docker

The project demonstrates how **real-time data processing, distributed systems, backend APIs, databases, authentication, and analytics** can be integrated into a single application.

---

## ✨ Key Features

### 🔐 User Authentication

- User registration
- Secure password hashing
- JWT-based authentication
- Login functionality
- Password validation
- Forgot-password interface
- Reset-password interface
- Protected application routes

### 🅿️ Parking Management

- 500 parking slots
- Real-time parking-slot status
- Available/occupied slot tracking
- Vehicle assignment to parking slots
- Vehicle entry and exit management

### 📡 Real-Time Event Processing

- Parking events generated by a simulator
- Apache Kafka used as the event streaming platform
- Kafka consumer processes parking events
- Parking-slot information updated automatically

### 🚘 Vehicle Management

- Vehicle entry tracking
- Vehicle exit tracking
- Vehicle information storage
- Parking duration calculation
- Parking records maintained in MongoDB

### 💰 Billing

- Parking fee calculation
- Parking transaction records
- Configurable parking rates
- Current parking rate: **₹20/hour**

### 📊 Analytics

The system is designed to provide parking analytics such as:

- Total parking slots
- Occupied slots
- Available slots
- Parking utilization
- Vehicle activity
- Parking transactions
- Revenue-related information

### 🐳 Dockerized Architecture

The complete application is containerized using Docker:

- FastAPI API
- MongoDB
- Apache Kafka
- Parking simulator
- Kafka consumer

This makes the project easier to run and deploy consistently.
